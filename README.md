# Assignment 1 - TypeScript

ไฟล์ที่เพิ่ม:

- assign1_1.ts  (ระบบคำนวณราคาสินค้าและส่วนลด)
- assign1_2.ts  (ระบบจัดการข้อมูลหนังสือ โดยใช้ Tuple)
- tsconfig.json
- package.json

คำสั่งที่ใช้:

1. ติดตั้ง TypeScript (ครั้งแรก):

```powershell
npm install
```

2. คอมไพล์ไฟล์ .ts เป็น .js:

```powershell
npm run build
```

ไฟล์คอมไพล์จะไปที่โฟลเดอร์ `dist`.

3. รันแต่ละตัวอย่างด้วย Node.js:

```powershell
npm run start:assign1_1
npm run start:assign1_2
```

คำสั่ง Git ที่ครูขอให้ส่งงาน (รันในโฟลเดอร์โปรเจค):

```powershell
git add .
git commit -m "ส่งงาน Assignment1_1 and Assignment1_2"
git push
```
